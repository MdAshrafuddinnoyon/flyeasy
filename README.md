# FlyEasy Tourism Platform

FlyEasy is a modern, full-stack travel and tourism platform built with React, Node.js, Express, and MySQL. It offers seamless booking for flights, holiday packages, and hotels.

## Features
- **Flight & Package Booking:** Search and book flights or complete holiday packages.
- **Admin Dashboard:** Complete CMS for managing site content, bookings, packages, and users.
- **Dynamic Content:** Edit heroes, logos, contact info, and FAQs directly from the dashboard.
- **Secure Authentication:** JWT-based login with role-based access control.
- **Hostinger Auto-Deploy:** Zero-configuration script to instantly deploy and install the MySQL database on shared hosting environments.
